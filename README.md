# Customer Retention & Churn Analysis

## Project Overview
This project analyzes customer churn data to identify retention patterns, churn behavior, and customer trends for a subscription-based business.

## Tools Used
- Python
- Pandas
- Streamlit
- Matplotlib

## Features
- Churn analysis
- Retention rate calculation
- KPI metrics
- Interactive dashboard
- Subscription analysis
